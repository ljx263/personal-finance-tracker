# Personal Finance Tracker
A beginner Python project developed while learning programming fundamentals. The program allows users to record expenses and view simple spending summaries.
## Overview
* This project was created as part of my efforts to learn Python through practical application.
* The objective was to build a simple expense tracking program that could record spending and generate basic summaries. By developing this project, I practised working with data structures, functions, loops, and user input handling.
* The project allowed me to move beyond learning syntax and apply programming concepts to a real-world scenario.
## Features
### Expense Recording
* Add expenses
* Assign spending categories
### Expense Viewing
*Display all recorded expenses
### Spending Analysis
*Calculate total spending
* Summarise spending by category
* Identify the highest recorded expense
## Programming Concepts Practised
* Variables
* Lists
* Dictionaries
* Functions
* Loops
* Conditional statements
* Data aggregation
* User input handling

* This project strengthened my understanding of Python fundamentals and encouraged me to continue exploring programming independently.
